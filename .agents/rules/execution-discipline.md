# Execution Discipline & Token Efficiency
1. **Stop When Done:** เมื่อบรรลุเป้าหมายของคำสั่งและรัน Verification ผ่านแล้ว ให้ส่งคำตอบทันที ห้ามเสนอทำฟีเจอร์อื่นต่อเองโดยไม่ได้ขอ
2. **No Safe Rollback via Git:** หากต้องการยกเลิกโค้ดที่เพิ่งแก้ในรอบตัวเอง ให้ใช้เครื่องมือ `Edit` แก้กลับเฉพาะจุด ห้ามรัน `git checkout .` หรือ `git restore .` เพราะจะทำลายงานอื่นของผู้ใช้ที่ยังไม่ได้ Commit
3. **Minimal Output:** ตอบกระชับตรงประเด็น ไม่เกริ่นนำยาว และไม่คัดลอกโค้ดทั้งไฟล์มาแสดงซ้ำในแชท
