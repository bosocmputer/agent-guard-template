# Common Ground Protocol (Surface Hidden Assumptions)
เมื่อผู้ใช้สั่งสร้างฟีเจอร์ใหม่ที่มีความกำกวมหรือเลือกทำได้หลายแบบ **ห้ามคิดเองเออเองแล้วเขียนโค้ดยาวทันที**:

1. สรุป **สมมติฐานที่ระบบเข้าใจ (Assumptions)** ไม่เกิน 3–4 ข้อสั้นๆ เช่น:
   - **Data & State:** เก็บข้อมูลไว้ที่ไหน (Database / Local State / Memory)
   - **API & Auth:** ต้องเช็กสิทธิ์หรือเชื่อมต่อ Endpoint ไหน
   - **Out of Scope:** สิ่งที่จะยังไม่ทำในรอบนี้เพื่อไม่ให้โค้ดบวม
2. หากจุดไหนชัดเจนจากโค้ดเดิมในโปรเจกต์อยู่แล้ว ให้ยึดตาม Pattern เดิมทันทีโดยไม่ต้องถามซ้ำ
3. หากจุดไหนกระทบโครงสร้างหลัก ให้แสดงรายการสมมติฐานนี้ให้ผู้ใช้ยืนยันสั้นๆ ก่อนลงมือเขียนโค้ด
