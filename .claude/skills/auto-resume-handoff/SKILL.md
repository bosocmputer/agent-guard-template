# Auto-Resume & Seamless Handoff Protocol
เมื่อผู้ใช้สั่งให้ทำต่อจากที่ค้างไว้ (เช่น "ทำต่อเลย", "แก้ต่อให้เสร็จ", "โควต้าอีกฝั่งหมด"):
1. ตรวจสอบไฟล์ `.agent-last-state.log` หรือ `TASK_STATE.md` (ถ้ามี)
2. รัน `git status --short` และ `git diff` เพื่อดูว่า Agent ตัวก่อนหน้าแก้ไขไฟล์และบรรทัดไหนค้างไว้
3. รันเทสต์ของไฟล์ที่กำลังแก้ไขอยู่ 1 ครั้งเพื่อดูสถานะปัจจุบันว่าผ่านหรือติด Error อะไร
4. ลุยงานส่วนที่เหลือต่อทันทีโดยไม่ต้องให้ผู้ใช้พิมพ์อธิบายซ้ำตั้งแต่ต้น
