# ขั้นตอนการทำ Database Migration อย่างปลอดภัย
1. ห้ามแก้ไขไฟล์ Migration เก่าที่เคยรันไปแล้วเด็ดขาด ให้สร้างไฟล์ Migration ใหม่เสมอ
2. หากเพิ่มคอลัมน์ใหม่ในตารางที่มีข้อมูลอยู่แล้ว ต้องกำหนดให้เป็น `NULL` ได้ หรือมีค่า `DEFAULT` เสมอ
3. ตรวจเช็กคำสั่ง SQL ที่ถูกสร้างขึ้นว่าไม่มีคำสั่ง `DROP TABLE` หรือ `DROP COLUMN` ที่ทำให้ข้อมูลสูญหายโดยไม่ตั้งใจ
